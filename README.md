# IDE Portfolio (Next.js + TypeScript + Tailwind)
1. `npm install`
2. `npm run dev` → http://localhost:3000
3. Update your details in `data/portfolio.ts` (links, project, education). Your resume lives at `public/resume.pdf` and is served at `/resume.pdf`.
4. Deploy: push to GitHub and import into Vercel (`npm run build` for a local check).

Terminal commands: `help`, `ls`, `open <file>`, `run [file]`, `clear`. Shortcut: Ctrl/Cmd+Enter runs the active file.
